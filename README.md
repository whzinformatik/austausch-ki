# Austausch zu KI

## Interessante Tools für den Betrieb **lokaler LLM**
* TensorFold, https://tensorfold.dev/
  * Run language models locally on Apple Silicon and NVIDIA GPUs with TensorFold
  * (November 2026: das klingt sehr interessant!)
* Stata, https://github.com/niko1221/strata
  * Run powerful AI on your own computer
  * (November 2026: das klingt interessant!)
* ModelFit, https://modelfit.io/
  * Find the Best Local AI Model for Your Device
  * Benchmark: `npx @modelfit/cli@latest bench`

## Dokumente für LLM aufbereiten
* MarkItDown, https://github.com/microsoft/markitdown
  * Wandelt PDF, DOCX, PPTX, XLSX u. a. in Markdown um, auch als MCP-Server
  * (November 2026)

## Erfahrungen und Empfehlungen

### Markdown als gemeinsames Format
* strukturierte Ablage von Markdown in einem Obsidian-Vault
* LLM bekommt Zugriff auf diesen Ordner und legt dort auch selbstständig Zwischenstände/Kontext etc. ab
  * Modelle navigieren und lesen nur nötige Dateien ein
  * Kontext einfach für verschiedene Modelle bereitstellbar
* (11/2026)
